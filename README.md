# Phishing Email Analysis

## Task 2 – Cyber Security Internship

### 📌 Project Overview

This project focuses on analyzing a simulated phishing email and identifying common phishing indicators and social engineering techniques.

### 🎯 Objective

The objective is to examine a phishing email sample and identify suspicious characteristics such as:

- Suspicious sender information
- Urgent and threatening language
- Social engineering techniques
- Suspicious URLs
- Generic greetings
- Brand impersonation
- Email authentication limitations

### 🔍 Analysis Performed

The following aspects were analyzed:

1. Sender Information
2. Subject Line
3. Email Body
4. URL
5. Spelling and Language
6. Email Headers
7. Phishing Indicators

### 🛡️ Safety Note

This project uses a **simulated training email** created for cybersecurity education. The suspicious URL was not opened, and no real credentials or personal information were entered.
